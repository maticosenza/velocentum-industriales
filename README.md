# Velocentum Industriales

Creá una landing industrial breve y sobria para Velocentum utilizando React, TypeScript y Tailwind. Aplicá el branding actual de Velocentum: negro, blanco, violeta #8A3FFC y naranja #F5451F, con tipografía moderna, alta legibilidad y diseño responsive.

Prepará solamente una estructura limpia y editable con estas secciones: navbar, hero, problemas industriales, sistema industrial, servicios, proceso de trabajo, casos Greenpac y Patagonia Vessels, CTA final y footer del ecosistema Velocentum.

Usá placeholders simples; no inventes textos extensos, métricas, testimonios ni imágenes. Los CTA serán “Solicitar una propuesta”, “Solicitar propuesta” y “Conversar sobre mi empresa”. No agregues diagnóstico e-commerce, Calendly, formularios, Meta Pixel ni publiques. Dejá el proyecto preparado para conectarlo a GitHub.
